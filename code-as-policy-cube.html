研究方向六类定义（点击展开）——并存的研究线，非互斥模式
组合是常态：这六条是多变量缝合出的一张研究地图，不是互斥的单变量刻度——研究者常组合多个策略，一篇论文可同时占多格（数据库给论文打多个方向 tag，方块由 tag 派生）。范本：ASPIRE=闭环+沉淀、ENPIRE=多智能体+闭环、CWM=世界模型+进化、Agent2World=世界模型+多智能体、DGM=进化+沉淀、SR-Platform=沉淀+多智能体、LEGO-Prover 跨技能/科研两场景。真正单变量的刻度是 Y 轴更新能力（机制冻结→RSI）。
单次生成：一次性生成即交付，无迭代——正确性靠 API/harness 设计约束（CaP、VisProg、Design2Code）。
闭环调整：生成→执行→诊断→修订的固定预算环，反馈来自真实执行结果（Self-Debugging、RoboInspector、AutoSciRub 的评分规则引导）。
进化搜索：养种群、并行评估、选择变异，人的品味被适应度+选择算子替代（Eureka、GEPA、AlphaEvolve）。
技能沉淀：哲学是“把一次性的成功变成可检索的资产”——优化对象不是当前任务而是库本身；用前期验证成本换取未来任务的边际成本趋零（摊销/复利）。知识留在库里而非权重里：可审计、可组合、可跨任务跨具身迁移（Voyager、ASPIRE、CRAFT、DreamCoder 的 wake-sleep 是其前 LLM 根——夜里压缩解程序为抽象，白天用抽象加速搜索）。
多智能体：把人的工作流角色拆成多个 agent 分工协作，或物理机队并行（MetaGPT、GenSwarm、AutoSafeCoder）。
世界模型：反馈/规划经由世界模型而非直接环境交互——闭环的反馈 oracle 被外包给可执行的模型模拟（WorldCoder 自建模型规划、CWM 在生成模型上搜索、WMRL 用世界模型预测替代真实执行训练科研 agent，提速 3–4×）。
记忆上下文（新方向）：改进机制是经验表示的管理本身在被改进——存储/检索/合并/遗忘策略可学习可进化（MemGPT 分页调度→Mem0 生产部署→A-MEM 记忆网络化→MemSkill 记忆操作可学→Parametric Memory 参数化跃迁→ReasoningBank 策略级记忆）。与技能沉淀的区别：技能是程序性知识（代码→执行），记忆是陈述性知识（表示→检索参考）。失效模式：记忆膨胀、幻觉、检索失败（vs 技能腐烂）。
更新能力五级定义（点击展开）
L0 机制冻结：机制完全固定，LLM 冻结，无任何自我改进（CaP、CodeAct 单次使用、Eureka 的 GPT-4 也冻结——进化发生在产物空间而非机制）。
L1 可自进化：不改权重，但修改 prompt / 流程 / 技能库 / 代码工件（DSPy、ADAS、Voyager、ENPIRE 改训练代码）。
L2 适应性输出：test-time training 式的推理时轻量适应，仅调输出概率/隐状态，事后不留权重（TTT 层、TTRL）。
L3 权重调整：正式的权重更新——LoRA/PEFT 部分更新或 SFT/RL 整体微调（CodeActAgent、Code-as-World-VL、FlowReasoner、VERITAS 回流训练、SEAL）。注：社区实践里 LoRA 只作工程实现手段，以“部分更新”本身为研究对象的工作为零（定向检索确认），故两种深度合并为一层。
L4 RSI 模式：权重/代码自我更新，且更新能力本身有越来越强的趋势——Darwin Gödel Machine 是教科书定义（“修改自己的代码，从而提升修改自己的能力”）。

三维视角下的结构性发现

1. 更新能力呈“沙漏形”分布

立方体堆在两端：L0 机制冻结（88 条）和 L3 权重调整（27 条）挤满，中间的 L1（26 条）、L2（4 条）稀薄。解读：这个领域要么把 LLM 当冻结的“代码发生器”用（在产物空间进化），要么直接动权重（烧进参数）——“轻量、可逆、推理时”的中间地带是断层。注：权重调整层内部有一个经定向检索坐实的事实——社区实践里 LoRA 只是工程实现手段，以“部分更新”本身为研究对象的工作为零（agent 微调代表作如 AgentTuning 全部整体 SFT；记忆中的 "ToolLoRA" 确认不存在），这正是 L3（LoRA）与 L4（整体训练）合并为一层的原因。L2 层正在长出来：TTT（架构层）+ TTRL（多数投票伪奖励做测试时 RL，NeurIPS 2025）。

2. RSI：从孤峰变成“垂直领域梯子”

严格意义的 L4 RSI 仍是两座孤峰：Darwin Gödel Machine（迭代改自身代码并维持谱系档案，SWE-bench 翻倍）和 Absolute Zero（零数据自博弈，未展示加速趋势，近邻）。但本轮调研发现 RSI 正以垂直领域梯子的方式落地——数学：STP 猜想者-证明者自博弈定理证明器 + Lean4 自引导自博弈（research×进化×L3 填掉，科研场景的进化梯子 L0 FunSearch→L1 AlphaEvolve→L3 STP→L4 AZR 四级完整）；软件/ML 工程：Socratic-SWE（解题痕迹作训练数据的闭环自进化）+ Live-SWE-agent（运行时现场自进化）+ Frontis-MA1（垂直 RSI 最完整形态：35B 模型经执行接地 SFT+RL 训成 MLE 元进化 agent，OpenMLE 全栈把可验证环境、算子学习与长程进化耦合单环，MLE-Bench Lite 39→71% 超GPT-5.5+Codex，权重开源）；药物发现：生成式分子优化的自改进采样（推理时预测器偏置生成器）；元层还有 Gödel Agent（ACL 2025——连优化模块都优化自己的自指框架，L1 形态）。理论侧：1250 篇论文的 RSI 综述判定当前 RSI 仍“受限”（接地/坍缩/算力三约束），内省阈值理论回答“自改进何时可持续何时退化”。SEAL（L3）仍是权重侧最近邻。

3. “可自进化”集中在元层，且性价比惊人

L1 层的立方体几乎全在 Agent 自身和技能/动作两行（ADAS/AFlow/DSPy/GEPA/EvoPrompt/Voyager/CRAFT/LATM/ENPIRE）——只有当被改的对象就是自己的机制时，“不改权重的自我改进”才成立。最新的性价比证据：GEPA（530 引用）用反思式 prompt 进化在六任务上平均胜 GRPO 6%、至多 20%，rollout 少 35×，还胜过 DSPy 的 MIPROv2 至多 10%——语言空间的 L1 进化在样本效率上碾压 L3 的 RL，这是沙漏中间层价值的第一个大规模实证。

4. 与“反馈栈”的关系

反馈栈（★证据/★★验证/★★★飞轮，弹窗内保留）描述反馈信号的质量，更新能力描述改进落在哪里，时间尺度两比特描述运行时行为——三者正交：Eureka 是 ★★×L0×B（验证强但机制不动），RoboPro 是 ★★×L3×A（飞轮转在权重上），DGM 是 ★★★×L1×B（全栈自指但权重不动），DERL 是 ★★★×L3×A（进化×梯度合流）。历史性更新：挂了十二轮的奖励×进化×L3 出现最近正主 DERL（2512.13399——可微进化发现最优奖励结构），加上 Large Reward Models（可迁移在线机器人 RM）与 LaRes（NeurIPS 2025），奖励×L3 生态从孤点 SER 扩成四篇；设计×技能沉淀 被 AssemCAD（可复用参数化组件工厂）+ CADIR（构造图检索）+ BRepCLIP（BRep 预训练检索）三篇填实——从 CAD 检索到组件复用的完整基础设施链。

5. 设计/规约行：本体域自带免费形式化 oracle

新增的设计行（青色立方体）全部落在 L0 平面（冻结 LLM），但它的潜力在 L1：本体域天生自带 OWL 推理机一致性检查 + SHACL 校验器这两个免费的形式化验证器——比世界域的“渲染对比”更便宜可靠。NL2SHACL 基准发现“语法有效但语义弱”后，Extended NeOn-GPT 已把验证接进环。两个高价值空格：ODP 沉淀环（Ontology Design Patterns 是本体社区 2010s 的存量技能库资产，无人接进 LLM 生成-验证-沉淀环——与约束×技能沉淀同构且 oracle 更便宜）和设计代码空间的进化搜索（渲染质量/推理一致性作适应度，与策略×进化同构）。

6. 世界模型的五种角色：从单一 oracle 到多面基础设施

世界模型在立方体中已分化出五种角色——同一种技术，五种不同的使用方式：

  • ① 反馈 oracle：替代真实环境给 agent 提供反馈（WorldCoder/CWM 在生成模型上搜索、LLM-MCTS/WebDreamer 冻结 LLM 当模拟器）——这是最原始的用法；
  • ② 训练场：世界模型无限生成合成环境来训练 agent（Agent World Model 1000+ 环境、Agent-World 自进化环境合成、SimWorld Studio UE5）——"不是 agent 在环境中学，而是环境进化逼 agent 学"；
  • ③ 过滤器：世界模型的预测偏差决定哪些经验值得存入记忆（Surprise-Gated Episodic Memory——V-JEPA 潜空间惊讶度门控记忆形成——JEPA 忽略不可预测细节的架构偏置被反转为噪声过滤器）；
  • ④ 想象空间：策略在世界模型内部 rollout 训练（Dreamer 系——MuZero→DreamerV3→Dreamer 4；PAN——LeCun 首个完整 GLP；Latent Planners——潜空间直接优化动作）——与 ① 的区别：不只是验证候选，而是在想象中生成新经验；
  • ⑤ 内在动机源：世界模型的预测误差（好奇心/新颖性）和可控性（赋权/胜任感）直接驱动 agent 去探索什么（SENSEI——VLM 蒸馏有趣度内在奖励；From Curiosity to Competence——内在动机从新颖性转向赋权的动力学）——"预测不准的地方就是值得学的地方"这条原则的三种用法：门控记忆（过滤器）、排序回放（Curious Replay）、驱动探索（好奇心）。

世界模型的方法论对偶——代码空间 vs 潜空间：前者（WorldCoder/CWM/Code-as-Worlds）生成可执行代码，可读可改可审计，MCTS 在代码上搜索；后者（PAN/Latent Planners/Dreamer）在 JEPA 式潜向量中预测，黑盒但语义紧凑，梯度/采样在潜空间规划。两种哲学在 wm 方向列中平行发展至今未合流。

本方向已聚成 11 格 21 篇，且贯穿四层形态：史前根与训练派（MuZero——CWM 的非 LLM 前身；DreamerV3→Dreamer 4——在可扩展世界模型内部直接训练 agent；DADS——动力学感知技能发现）；冻结 LLM 直接当模拟器（LLM-MCTS、WebDreamer、RAP——把 LLM 同时当世界模型和推理器“先模拟再回答”的奠基作）；生成代码世界模型再在其上搜索（WorldCoder、CWM、GIF-MCTS、PoE-World、Agent2World）；训练出来的世界模型（WMA、RWML、WMRL、SafeDreamer——想象内安全规划、LUCID——想象动力学中的潜技能发现）。共同哲学：反馈来源从“真实环境”变成“模型模拟”，真实执行贵就造模拟器。与“世界”场景行的区别：场景行问世界模型是不是产物，方向列问反馈是否经由世界模型。综述锚点：Text World Models for LLM-based Agents、代理模型→自主设计；评测标尺：From Word to World。配套的 AutoSciRub（先归纳可执行评分规则再改进）则代表闭环方向的“评估先行”支线。
